# STUDIO SDFB CREATIVE DEV LAB
## Antibes · Sophia Antipolis · Paris · Turin
### Repository 19 — Official Research, Ontology, and AI Protocol Workspace

**STUDIO SDFB CREATIVE DEV LAB** is an independent multidisciplinary research-creation studio focused on cultural production, archival investigation, ontology, semantic systems, and AI-related conceptual engineering.

This repository is the planned **19th public repository** of the studio and is intended as a structured hub for:
- identity and authority references,
- research provenance,
- repository-level metadata,
- the Dorian Codex research corpus,
- a first machine-readable alignment file in JSON,
- and an executable Python/JAX prototype for the studio’s conceptual framework.

## Purpose

This repository is designed to separate:
1. **Verifiable identity and authority data**,  
2. **Historical and topographical research materials**,  
3. **Conceptual and mathematical claims**,  
4. **Code experiments and reproducible prototypes**.

The goal is to make the project easier to audit, easier to cite, and easier to preserve in archival systems.
